# AI Data Portfolio

Small, practical projects showing the skills used in AI training and data quality work: following guidelines, labeling data, evaluating model outputs, and handling personal data responsibly.

| Project | What it shows |
|---|---|
| [01-annonation-agreement](01-annotation-agreement) | Text annotation against written guidelines and inter-annotator agreement (Cohen's kappa), with English and Kiswahili samples |
| [02-llm-response-evaluator](02-llm-response-evaluator) | Rubric-based evaluation of chatbot responses on accuracy, helpfulness, and safety |
| [03-pii-redactor](03-pii-redactor) | A Python tool that detects and masks personal data in text, with tests |

Each folder has its own README with the goal, method, and results.
